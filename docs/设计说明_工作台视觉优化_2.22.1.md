# 工作台视觉设计说明 · 2.22.1

## 目标

为现有 LawCase 工作台做一次不改变业务的视觉收敛：让律师能快速区分「案件上下文」「主操作」「当前阶段」「台账内容」和「需要处理的异常」。

## 设计方向

- **定位**：法律案件操作台，而不是通用 CRUD 表格。
- **基调**：浅色、克制、可信；白色内容面配低对比背景层，品牌色只用于当前项和主操作。
- **信息层级**：
  1. 案件标题与绑定状态
  2. 案件动作（新建、扫描、交付、重读）
  3. 页签与核对进度
  4. 主内容与结果
  5. 底部阶段导航与下一步
- **交互语言**：主操作有实心品牌色；辅助操作为轻边框；危险操作使用错误色；加载、错误和空状态都有语义提示。

## 本轮实现

### 视觉层

- 工具栏使用低对比背景与细分隔线，降低大片空白的漂浮感。
- 主内容区保持白色，侧栏使用轻微灰阶区分辅助导航。
- 按钮统一为 34px 最小高度、8px 圆角、轻阴影；主按钮增加品牌色阴影，悬停时抬升层级。
- 页签高度统一为 42px，当前页签使用极浅品牌色底，避免只有一条底线导致当前页不明显。
- 空状态使用 10px 圆角、虚线边框和浅色底面，作为可识别的信息区块。
- AI 抽屉继续使用绝对定位，不改变主内容宽度；窄屏覆盖整个右侧工作区。

### 响应式层

- 980px 以下：案件侧栏上移，主内容保持可用宽度。
- 640px 以下：页签横向滚动，案件标题允许换行，路径限制高度并可滚动。
- `prefers-reduced-motion` 下关闭按钮过渡。

## 假设与取舍

- 截图展示的是工作台实际业务内容，但截图像素不等于 CSS 逻辑像素；本轮只把截图作为视觉方向和问题基线，不做像素级还原。
- 没有引入新字体、图标库、图片或第三方组件；沿用宿主 `--dsw-alias-*` 主题 Token。
- 没有改变 API、字段、权限和业务判断；视觉优化优先于新增功能。
- 没有把结果提示做成全局浮层，以免遮挡案件内容；继续放在当前上下文附近。
